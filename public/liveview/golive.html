    Create the YouTube Live stream

    The camera, whether we install it or you do, pushes to a persistent YouTube stream key. LiveView only embeds the watch link.

    1. In YouTube Studio, verify the channel and enable live streaming. The first time can take up to 24 hours.
    2. Create a persistent stream key A reusable key, not a one-time event key, so the camera can reconnect with the same settings.. Do not email the key in the install form.
    3. Set visibility to Unlisted or Public. Unlisted is a good start.
    4. Turn on DVR Viewers can rewind the live broadcast instead of only joining at the current moment..
    5. Copy the watch URL or the channel live URL (youtube.com/@yourchannel/live).

    Twitch alternative: create a stream key in the Creator Dashboard and copy your twitch.tv channel URL. Vimeo and a public .m3u8 link work the same way on the next step.
