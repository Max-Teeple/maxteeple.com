# Brand assets (committed to git)

Files here are **deployed with every build** — unlike user uploads in `/uploads`.

- `liveview-logo.svg` — default LiveView logo (used site-wide in headers, favicons, and PWA)

User-uploaded course logos, profile photos, and stream previews are **not** stored here.
They go to S3 or a Render persistent disk — see `docs/MEDIA_STORAGE.md`.
