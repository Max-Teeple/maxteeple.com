Privacy policy

15 October 2026

Glance is a private personal dashboard owned by Max Teeple. It is for his own use. It is not offered to the public, and it does not have other users.

Google Calendar

Glance uses the Google Calendar API for one Google account, max.teeple@gmail.com. It uses that access only to create events on the owner's calendar and to read that calendar so the events can be shown on the dashboard. Glance does not use Google data for advertising or for any other purpose.

How tokens are stored

Google access tokens and the refresh token are stored only on Glance's server. The refresh token is encrypted before it is saved. Tokens are not sent to the browser and are not written into the app's public pages.

Sharing

Glance does not sell personal data. It does not share calendar data, tokens, or other personal information with advertisers, data brokers, or other companies.

Revoking access

The owner can disconnect Google inside Glance at any time. Access can also be revoked in Google Account permissions. After access is revoked, Glance can no longer create or read calendar events.
